# Projects: Embedding a Decision Model in Existing Infrastructure

Community projects that use this shape, grouped by sub-type. Numbers are author-reported. An entry with no model in parentheses ran on TypeSafe Jev; every other entry names its model. The shape, code sketch, variants, and field lessons are in `prior-art/embedding-in-infrastructure.md`.

**Databases and search**
- pg-jev (Postgres extension): [realZachi/pg-jev](https://github.com/realZachi/pg-jev), [pgjev.com](https://pgjev.com)
- sqlite-jev (extension + virtual table): [mgaitan/sqlite-jev](https://github.com/mgaitan/sqlite-jev)
- mysql-ailike (`AILIKE` plugin): [maayanlevy/mysql-ailike](https://github.com/maayanlevy/mysql-ailike), [HN](https://news.ycombinator.com/item?id=49774592)
- duckdb-jev: [colliber/duckdb-jev](https://github.com/colliber/duckdb-jev). JevQL: [kylemclaren/jevql](https://github.com/kylemclaren/jevql), [flaviocopes.com](https://flaviocopes.com/jev/). vgi-typesafe: [Query-farm/vgi-typesafe](https://github.com/Query-farm/vgi-typesafe)
- neo4jev (graph walking): [jexp/neo4jev](https://github.com/jexp/neo4jev)
- LanceDB `TypeSafeReranker`: [lancedb/lancedb](https://github.com/lancedb/lancedb) `python/python/lancedb/rerankers/typesafe.py`. OpenViking reranker: [volcengine/OpenViking](https://github.com/volcengine/OpenViking)
- Databricks `ai_decide`, a built-in SQL function returning Noul, Choice (1–255) and Score (2–10) as a VARIANT. Beta (Databricks decision model): [docs](https://docs.databricks.com/aws/en/sql/language-manual/functions/ai_decide), [blog](https://databricks.com/blog/introducing-aidecide-make-fast-decisions-your-governed-data)
- pg_typesafe, a Postgres C extension that batches 32 texts per request; reported 27× faster than per-row calls: [giuliosmall/pg_typesafe](https://github.com/giuliosmall/pg_typesafe), [write-up](https://aiskill.market/blog/jev-inside-databases-pg-typesafe-duckdb-jev)
- jev4pg, Postgres SQL jobs that keep probabilities apart from thresholds so policy changes replay with no new inference: [Sheltercosmo/jev4pg](https://github.com/Sheltercosmo/jev4pg)
- duckdb-jev (prasanthj), a C++ extension with per-query budgets, two-tier cache and `jev_stats()`; reported 1,943 rows/s: [prasanthj/duckdb-jev](https://github.com/prasanthj/duckdb-jev)
- jev-orderby-bench, tests whether `ORDER BY` a probability is defensible; passes on topic labels, fails 4 of 6 gates on product relevance: [yodablocks/jev-orderby-bench](https://github.com/yodablocks/jev-orderby-bench)
- llama-index-jev, a LlamaIndex reranker and router; reported nfcorpus nDCG@5 0.340→0.396: [WiktorB2004/llama-index-jev](https://github.com/WiktorB2004/llama-index-jev). Milvus reranker adapter: [milvus-io/milvus-model](https://github.com/milvus-io/milvus-model), [bootcamp notebooks](https://github.com/milvus-io/bootcamp/tree/master/bootcamp/RAG/search_with_jev)

**Gateways, proxies, and edge**
- LiteLLM pass-through at `/typesafe/*` with logging and cost tracking; spend is logged under the resolved version: [docs.litellm.ai](https://docs.litellm.ai/blog/typesafe_jev)
- Cloudflare Workers AI binding `env.AI.run("@cf/cloudflare/clef-flash", …)` or REST; reported 38.8 ms median for Clef-flash (Clef, Clef-flash): [flaviocopes.com](https://flaviocopes.com/clef/), [developersdigest.tech](https://www.developersdigest.tech/blog/cloudflare-clef-decision-models-2026), [cascade cost guide](https://rohitai.com/blog/cloudflare-clef-decision-models-agent-routing-workers-ai)
- Tiltmeter, a `/v1/systemone` proxy that alerts without labels on version switches, drift, and answers crowding a threshold: [abe75ch/tiltmeter](https://github.com/abe75ch/tiltmeter). Jeview, a proxy that logs decisions to SQLite with a live dashboard: [andududu/jeview](https://github.com/andududu/jeview)
- stuntd, a learning proxy that trains a head per decision site, shadows, then serves locally with provider fallback; reported 71–99% local coverage (Laya, Jev): [bladedevoff/stuntd](https://github.com/bladedevoff/stuntd)
- jev-switch, a Rust DAG router with failover across Vercel, TypeSafe, OpenRouter and local Laya (Jev, Laya): [ARCJ137442/jev-switch](https://github.com/ARCJ137442/jev-switch)
- Coding-agent routers: Switchboard picks model and effort once per conversation, reported 0.55 s median (Jev; Laya experimental): [ruban-24/switchboard](https://github.com/ruban-24/switchboard). laya-code-router, a loopback proxy with a local sidecar, reported 200–500 ms on an M2 Max (Laya): [SupremeDreamZ/laya-code-router](https://github.com/SupremeDreamZ/laya-code-router)
- rotom, an OpenAI/Anthropic-compatible local gateway: [RyanKung/rotom](https://github.com/RyanKung/rotom). safer-with-jev, a Neon AI Gateway proxy: [andrelandgraf/safer-with-jev](https://github.com/andrelandgraf/safer-with-jev)
- ry, a Workers 404 router: rules and typo fixes first, then Clef picks the target. Redirects at ≥0.7, or ≥0.5 with a 3× lead over the runner-up. Reported 76% fixed without the model, 97% including suggestions, on a 662-page site (Clef): [ygwyg/ry](https://github.com/ygwyg/ry)
- claude-router, a Claude Code turn-hook mod that sets model tier and effort once per logical turn, with no proxy. Savings not measured (Jev or Clef/Clef-flash): [alexei-led/claude-router](https://github.com/alexei-led/claude-router)
- BrighTO-Router, a Rust LLM gateway exposing `/v1/systemone` and `/v1/decisions` as a separate adapter surface. Reported ~2 ms p50 router overhead (Laya, Ollaya, Jev-compatible): [thusinh1969/BrighTO_Router](https://github.com/thusinh1969/BrighTO_Router)
